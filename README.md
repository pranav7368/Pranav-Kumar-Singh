## Local preview

No build step is required. Clone the repository and open `index.html`, or serve the directory with any static HTTP server.

```bash
git clone https://github.com/pranav7368/Pranav-Kumar-Singh.git
cd Pranav-Kumar-Singh
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Content standards

The portfolio distinguishes between:

- **Production work** — externally available products with a verifiable link
- **Completed prototypes** — implemented projects that are not production services
- **Ongoing/private work** — projects still being developed or reviewed before public release

Claims about performance, scale, rankings, or production readiness should be included only when supporting evidence is available.
